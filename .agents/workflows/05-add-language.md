# Workflow: Add or Update a Dashboard Language

1. Add locale code and human-readable language name to the language registry.
2. Add complete translation dictionaries for all namespaces.
3. Keep key names identical across locales.
4. Run missing-key and unused-key checks.
5. Verify date, number, currency and plural formatting.
6. Check font rendering, overflow, truncation and table/chart layouts.
7. Review all high-risk terms: issue categories, maintenance actions, status, priority, uncertainty, and reviewer decisions.
8. Keep complaint original text unchanged; translations are separate fields with source and review status.
9. Have a proficient speaker review critical strings before claiming language quality.
